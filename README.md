# cpp.org.ua

The website of [C++ Ukraine](https://cpp.org.ua), the Ukrainian C++ community.

Plain HTML and CSS with no build step: GitHub Pages publishes the `main` branch as is.

## Editing

Every page exists in Ukrainian and English (`index.html` and `en/index.html`, `rules/index.html` and `en/rules/index.html`), so change both.

Preview locally with `python3 -m http.server 8000` and open http://localhost:8000.

The link preview images and Telegram avatars are rendered from the templates in `brand/`; the commands are at the top of each template.

Code, comments and commit messages are in English.
